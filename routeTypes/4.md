# Route type `4` — URI

## Status

Accepted

## Summary

`target` is a URI encoded as a UTF-8 string (e.g. `https://…`, `ipfs://…`, or an
application deep link).

## Encoding

Set `routeType` to `4`. `target` MUST be the UTF-8 bytes of a non-empty URI string
(no null terminators).

Example (TypeScript / `ethers`):

```ts
import { toUtf8Bytes } from "ethers";

const uri = "https://example.com/claim/airdrop";
const target = toUtf8Bytes(uri); // Uint8Array of UTF-8 bytes
```

Other schemes encode the same way, e.g. `ipfs://bafy…` or `myapp://pay/…`.

## Decoding

```ts
import { toUtf8String } from "ethers";

if (target.length === 0) {
  throw new Error("invalid type 4 target length");
}

const uri = toUtf8String(target);
// parse / validate `uri` for the schemes the application supports
```

1. Require `target.length > 0`.
2. Decode `target` as UTF-8 into a string.
3. Parse and validate as a URI for the schemes the application supports.
4. Reject empty or invalid strings for this type.
