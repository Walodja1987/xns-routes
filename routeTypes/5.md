# Route type `5` — EVM route builder

## Status

Draft

## Summary

`target` is a 20-byte Ethereum address of a **route builder** contract. Applications
pass off-chain parameters (e.g. `?to=…&amount=…`) into the builder’s
`build(...)` view, which returns a transaction template
`(targetChainId, target, value, data)`.

This is the parameterized alternative to type [`3`](./3.md) (fixed calldata).

The expected builder surface is documented by
[`IXNSRouteBuilderV1`](../contracts/src/interfaces/IXNSRouteBuilderV1.sol)
(`suggestedRouteName`, `title`, `getParamSpecs`, and the route-specific `build(...)`).

## Encoding

Set `routeType` to `5`. `target` MUST be exactly 20 raw address bytes (same layout
as type [`0`](./0.md)).

Example (TypeScript / `ethers`):

```ts
import { getBytes } from "ethers";

const builder = "0xAbc0000000000000000000000000000000000Def";
const target = getBytes(builder); // Uint8Array, length === 20
```

Example shared link (only the route is on-chain; params are off-chain):

```text
usdt@action/transfer-usdt?to=0x1234…abcd&amount=100
```

## Decoding

```ts
import { getAddress, hexlify, Contract } from "ethers";

if (target.length !== 20) {
  throw new Error("invalid type 5 target length");
}

const builder = getAddress(hexlify(target));

// 1. eth_call getParamSpecs() on `builder`
// 2. Map query params (?to=&amount=) into build(...) argument order
// 3. eth_call build(...) → { targetChainId, target, value, data }
```

1. Require `target.length == 20`.
2. Interpret as an EVM builder contract address.
3. Read `getParamSpecs()`, map off-chain query params by name, call `build(...)`.
4. Reject any other length for this type.

## Security considerations

Freezing a route guarantees that the builder address cannot change; it does not
guarantee immutable builder behavior. Builders used as immutable endpoints SHOULD
be non-upgradeable and SHOULD avoid privileged mutable state that can alter generated
transactions. Applications MUST treat builder output as untrusted and validate or
display the resulting transaction before execution.
