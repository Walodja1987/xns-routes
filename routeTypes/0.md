# Route type `0` — EVM address

## Status

Accepted

## Summary

`target` is a 20-byte Ethereum (EVM) address.

## Encoding

Set `routeType` to `0`. `target` MUST be exactly 20 raw address bytes.

Example (TypeScript / `ethers`):

```ts
import { getBytes } from "ethers";

const address = "0xAbc0000000000000000000000000000000000Def";
const target = getBytes(address); // Uint8Array, length === 20
```

## Decoding

```ts
import { getAddress, hexlify } from "ethers";

if (target.length !== 20) {
  throw new Error("invalid type 0 target length");
}

const address = getAddress(hexlify(target)); // checksummed 0x…
```

1. Require `target.length == 20`.
2. Hex-encode and normalize with `getAddress` (or equivalent).
3. Reject any other length for this type.
