# Route type `0` — EVM address

## Status

Accepted

## Summary

`target` is a 20-byte Ethereum (EVM) address.

## Encoding

Set `routeType` to `0`. `target` MUST be exactly 20 raw address bytes (no ABI left-padding).

Example (TypeScript / `ethers`):

```ts
import { getBytes } from "ethers";

const address = "0xAbc0000000000000000000000000000000000Def";
const target = getBytes(address); // Uint8Array, length === 20
```

Do **not** ABI-encode the address as a 32-byte word — `target` must be the raw 20 bytes.

## Decoding

```ts
import { getAddress, hexlify } from "ethers";

if (target.length !== 20) {
  throw new Error("invalid type 0 target length");
}

const address = getAddress(hexlify(target)); // checksummed 0x…
```

1. Require `target.length == 20`.
2. Hex-encode and normalize with `getAddress` (or equivalent).
3. Reject any other length for this type.

## Non-goals

- Does not encode chain id (apps infer chain elsewhere, or use another type).
- Does not encode calldata or a transaction template.
- Does not imply the address is an EOA vs contract.

## Compatibility notes

Wallets and indexers that claim support for type `0` MUST treat any `target`
length other than 20 as invalid for this type.
