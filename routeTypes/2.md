# Route type `2` — Solana pubkey

## Status

Accepted

## Summary

`target` is a 32-byte Solana ed25519 public key (raw bytes, not Base58 text).

## Encoding

Set `routeType` to `2`. `target` MUST be exactly 32 raw ed25519 public key bytes
(not a Base58 string).

Example (TypeScript / `@solana/web3.js` style):

```ts
import { PublicKey } from "@solana/web3.js";

const pubkey = new PublicKey("7EcDhSYGxXyscszYEp35KHN8vvw3svAuLKTzXwCFLtV");
const target = Buffer.from(pubkey.toBytes()); // length === 32
```

Do **not** store the Base58 string as UTF-8 under this type — use a different
type if a textual encoding is required.

## Decoding

```ts
import { PublicKey } from "@solana/web3.js";

if (target.length !== 32) {
  throw new Error("invalid type 2 target length");
}

const pubkey = new PublicKey(target);
```

1. Require `target.length == 32`.
2. Interpret as a Solana `PublicKey` / ed25519 pubkey.
3. Reject any other length for this type.
