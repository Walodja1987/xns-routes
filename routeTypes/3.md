# Route type `3` — EVM calldata

## Status

Accepted

## Summary

`target` is raw EVM transaction calldata (function selector plus ABI-encoded
arguments). Destination contract and chain are chosen by the application out of
band (e.g. another route, UI context, or config).

## Encoding

Set `routeType` to `3`. `target` MUST be non-empty raw calldata bytes (not a
hex string, not UTF-8 text).

Example (TypeScript / `ethers`):

```ts
import { Interface, getBytes } from "ethers";

const iface = new Interface([
  "function transfer(address to, uint256 amount)",
]);

const data = iface.encodeFunctionData("transfer", [
  "0xAbc0000000000000000000000000000000000Def",
  1_000_000n,
]);

const target = getBytes(data); // Uint8Array, length > 0
```

For **parameterized** calldata (e.g. recipient and amount chosen when the link is
opened), store a builder contract address under route type [`5`](./5.md) instead of
embedding fixed arguments in type `3`.

## Decoding

```ts
import { hexlify } from "ethers";

if (target.length === 0) {
  throw new Error("invalid type 3 target length");
}

const data = hexlify(target); // 0x-prefixed hex for eth_sendTransaction.data / eth_call
```

1. Require `target.length > 0`.
2. Treat `target` as the `data` field of an EVM transaction or call.
3. Reject empty payloads for this type.
