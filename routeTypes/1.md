# Route type `1` — Bitcoin address

## Status

Accepted

## Summary

`target` is a Bitcoin payment address encoded as a UTF-8 string (e.g. Legacy,
P2SH, or Bech32/Bech32m).

## Encoding

Set `routeType` to `1`. `target` MUST be the UTF-8 bytes of a Bitcoin address string
(non-empty; no `0x` prefix; no null terminators) — e.g. Legacy, P2SH, or Bech32/Bech32m.

Example (TypeScript / `ethers`):

```ts
import { toUtf8Bytes } from "ethers";

const address = "bc1qxy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh";
const target = toUtf8Bytes(address); // Uint8Array of UTF-8 bytes
```

Other valid address strings encode the same way, e.g. Legacy (`1A1z…`) or P2SH (`3J98…`).

## Decoding

```ts
import { toUtf8String } from "ethers";

if (target.length === 0) {
  throw new Error("invalid type 1 target length");
}

const address = toUtf8String(target);
// validate `address` with a Bitcoin address library for the intended network
```

1. Require `target.length > 0`.
2. Decode `target` as UTF-8 into a string.
3. Validate with a Bitcoin address library appropriate for the networks the
   application supports (mainnet / testnet / etc.).
4. Reject if the string is not a valid address for the intended network.
